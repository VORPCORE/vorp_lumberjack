# vorp_lumberjack

Lumberjack Script for VORP Core

![Screenshot_6](https://user-images.githubusercontent.com/101003021/190474610-6833924d-58be-4101-a14a-5493445ee5a0.png)

## Installation
- `ensure vorp_lumberjack` in your `server.cfg / resources.cfg`
- `ensure vorp_lib` in your `server.cfg / resources.cfg`
- the axe item (`Config.Axe`) must be usable in your database

## Features
- Chop trees and get items 
- Use the axe item to hold it, use it again to put it away
- This script uses the tool with durability "metadata"
- Forbid cutting down trees in cities if you want
- Random messages when the skill bar fails

## Dependencies
- [VORP Core](https://github.com/VORPCORE/vorp-core-lua)
- [vorp_lib](https://github.com/VORPCORE/vorp_lib)
